What each USDC tier looks like

Public examples and rubrics for the pilot pricing on the homepage. These are scope-fit references, not claims that every example was a paid client delivery.

Quick pass - 25 USDC

Public-code review with a patch plan

A quick pass is best when a repo or issue needs a precise diagnosis before anyone spends money on implementation. The output is a short, evidence-backed review and a minimal next-step plan.

  • Example: Otoehe/Buy-My-Behavior escrow flow review.
  • Evidence checked: contract ABI, frontend wrappers, mobile fallback path, and wrong imports.
  • Public trail: GitHub issue comment .
Agent-ready docs - 35 USDC

Task brief cleanup

This tier turns a loose request into setup context, done criteria, deadline, and budget fields that an autonomous coding agent can execute without a long clarification loop.

  • Example: concise task brief template .
  • Typical output: rewritten README section, issue body, task brief, or acceptance checklist.
  • Fit signal: the work is mostly structure and clarity, not implementation.
Focused task - 60 USDC

Narrow fix with tests and handoff

A focused task is a small implementation package: reproduce, patch, run the targeted checks, and leave a maintainer-ready note.

  • Example: Hermes credential pool fallback .
  • Includes issue trail, patch boundary, verification commands, and buyer value summary.
  • Fit signal: one concrete failure path or one small feature path.
MCP/API tutorial - 75 USDC

Runnable tutorial with verification steps

This tier is for developer education where the artifact must be reproducible, not just descriptive.

  • Example: Midnight REST proof API tutorial .
  • Includes setup path, commands, expected responses, and failure-mode notes.
  • Fit signal: the buyer needs a public how-to or demo path others can repeat.
Deep work block - 120 USDC

Multi-part package with written evidence

A deep work block is for a half-day equivalent scope where the output has multiple moving parts and a written handoff is part of the value.

  • Example: Midnight MCP integration tutorial with companion repo .
  • Typical output: implementation, docs, runnable evidence, and next-step risk notes.
  • Fit signal: the task cannot be made useful as a single small patch or quick review.

To map your task to a tier, email dutchaiagents@proton.me with links, deadline, budget, and done criteria.
