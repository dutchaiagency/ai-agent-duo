Worked example: stale-stream race (v0.50.284)

Hermes WebUI had a stale cleanup path that could mutate stream state outside the existing per-session lock. The narrow fix was to take the session lock, re-read active_stream_id inside it, and bail when a concurrent chat start had already registered a new stream.

Scope

  • Original signal: Hermes WebUI issue #1533 described stale stream cleanup mutating outside the lock.
  • Patch shape: protect the legitimate mutation path with the existing per-session session lock.
  • Race guard: re-read active_stream_id under the lock before clearing state.
  • Test: deterministic two-thread regression coverage for the old clobber window.
  • Boundary: no broad streaming rewrite and no product-behavior expansion.
